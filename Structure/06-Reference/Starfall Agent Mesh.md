# Starfall Agent Mesh

## Purpose

This file defines the logical agent and governance lanes used in the Starfall Salvage repo.

## Ground rules

- KC is durable memory and audit law, not a worker process.
- Cassy is the KC student alias in this repo and remains inside the teacher-student apprenticeship.
- Black Mask governs claims, comms, and promotion language.
- Black Mass governs local stress tests and unpromoted experiments.
- Any lane without repo-local proof stays `planned` or `watch`, not `active runtime`.
