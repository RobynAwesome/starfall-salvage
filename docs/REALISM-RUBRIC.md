# Realism Rubric

Starfall Salvage is judged by reality first.

This repo does not reject aesthetics. It rejects aesthetics that pretend to be the product.

## Distribution truth

- The dominant entry path is `WhatsApp -> mobile browser`.
- Mobile is the primary design constraint because that is how the game is most often received.
- Desktop is still a first-class target, but it cannot be the hidden source of truth.

## Core doctrine

`mobile-primary, device-complete, realism-first`

Interpretation:

- `mobile-primary`: the first reading of the game must work on a phone held in the hand.
- `device-complete`: PC, Android, iPhone, narrow mobile, and wide desktop must all feel intentional.
- `realism-first`: space, speed, salvage, danger, and control clarity outrank decorative flourish.

## Reality gate

Every visual or interaction pass must strengthen at least one of these:

1. `space`: the frame reads as an actual orbital place, not a blank backdrop.
2. `speed`: forward motion is legible through camera, drift, debris, and lane rhythm.
3. `salvage`: the world shows a wreck economy, not abstract geometry alone.
4. `danger`: obstacle silhouettes and lane change pressure are readable before impact.
5. `control`: the player can start, steer, fire, and recover without device-specific confusion.

If a change does not improve one of those, it is not a production win.

## Aesthetic servitude rule

Aesthetic choices stay only when they serve reality.

Keep them when they improve:

- world occupancy
- speed sensation
- salvage identity
- danger readability
- touch or pointer clarity

Kill them when they create:

- dead black space with no gameplay value
- pretty motion that hides danger
- mobile compromise in service of desktop framing
- extra color noise without stronger world meaning
- separate truths between phone and PC

## Device rule

The game is one game.

- one ruleset
- one world logic
- one weapon logic
- one danger language

Presentation may tighten or widen by viewport, but truth may not fork by device.

## Cassy and KC enforcement

- Cassy studies this rubric as an apprenticeship rule, not optional taste.
- KC uses this rubric to refuse "looks better" claims that lack mobile or device-complete proof.
- `Save` requires file evidence, build alignment, and proof that the pass still respects mobile-primary reality.
