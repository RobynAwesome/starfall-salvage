## 🚀 **What Is Starfall Salvage?**

Starfall Salvage is a **WebGL space salvage runner** where players navigate orbital debris fields, collect resources, and build sovereign capability — while the system teaches financial literacy, risk management, and sovereign economics through gameplay.

It is also a **B2B lead generation funnel**: when a Microsoft VC plays Starfall and reaches for their wallet, that is the inlane converting cultural capital to financial capital.

---

## ⚡ **Core Features**

### 🎮 **Gameplay**
* **3-Lane Runner:** Fixed 3-lane snap mechanics (A/D or Swipe) through orbital debris
* **Reaction Tap Revive:** Mini-game with sequential spawns and reflex testing
* **Gender Ecosystem:** Male (XY) / Female (XX) adaptive UI variables synced to pilot profile
* **Product Discovery:** Elegant one-question survey active every 5 runs
* **Premium Glassmorphism:** 99% canvas focus, transparent overlays, sovereign aesthetic

### 📱 **Platform Coverage**
* **Web:** Live at [starfallsalvage.kopanolabs.com](https://starfallsalvage.kopanolabs.com)
* **PWA:** Installable, offline flight enabled via Service Worker
* **Microsoft Store:** Manifest + Service Worker ready for store submission
* **Mobile (Ionic):** Monorepo rebuild for Android/iOS via Capacitor

### 🏗️ **Architecture (Monorepo)**
```
starfall-salvage/
├── apps/                    # Application targets
│   └── mobile/              # Ionic React mobile rebuild
├── packages/                # Shared packages
├── src/                     # WebGL game source
├── backend/                 # Python SQLite server (pilot profiles, scores)
├── Store/                   # Microsoft Store assets
├── Structure/               # KC governance structure
├── docs/                    # Documentation
├── index.html               # Web entry point
├── service-worker.js        # Offline flight
├── manifest.webmanifest     # PWA manifest
├── turbo.json               # Monorepo orchestration
└── vercel.json              # Deployment config
```

## ⚙️ **Installation & Setup**

**1. Clone the Repository:**
```bash
git clone https://github.com/Kopano-Labs/starfall-salvage.git
cd starfall-salvage
```

**2. Run the Web Game (no build required):**
```bash
python -m http.server 8765
```
Visit `http://localhost:8765` — game runs immediately.

**3. Run with Backend (pilot profiles + score sync):**
```bash
python backend/starfall_server.py --port 8765
```

**4. Monorepo Development (Ionic mobile + packages):**
```bash
npm install
npm run dev
```
