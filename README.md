## 🚀 **What Is Starfall Salvage?**

Starfall Salvage (Star 4) is a **WebGL space salvage runner** where players navigate orbital debris fields, collect resources, and build sovereign capability — while the system teaches financial literacy, risk management, and sovereign economics through gameplay.

It is also a **B2B lead generation funnel and salvage intelligence layer**: serving existing mines and contractors under South Africa's tightening compliance, transformation, logistics, and commodity-volatility environment.

Governed by **Eddie BGF Mining** — Sector 02 Lead in the KPGS Agent Swarm.

## ⚡ **Core Features**

### 🎮 **Gameplay & Combat**
* **3-Lane Runner:** Fixed 3-lane snap mechanics (A/D or Swipe) through orbital debris
* **5 Weapon Calibres:** Bolt lane, Scatter burst, Pierce core, Rail lance, and Nova fan
* **Orbital Wreck Lane:** Curved salvage corridor, space backdrop, camera banking, and screen-fill frame pass
* **Reaction Tap Revive:** Mini-game with sequential spawns and reflex testing
* **Gender Ecosystem:** Male (XY) / Female (XX) adaptive UI variables synced to pilot profile
* **Product Discovery:** Elegant one-question survey active every 5 runs
* **Premium Glassmorphism:** 99% canvas focus, transparent overlays, sovereign aesthetic

### 📱 **Platform Coverage**
* **Web:** Live at [starfallsalvage.kopanolabs.com](https://starfallsalvage.kopanolabs.com)
* **PWA:** Installable, offline flight enabled via Service Worker (`20260526-ready-shell`)
* **Microsoft Store:** Manifest + Service Worker ready for store submission
* **Mobile (Ionic):** Monorepo rebuild for Android/iOS via Capacitor

## ⚙️ **Installation & Setup**

**1. Clone the Canonical Repository:**
```bash
git clone https://github.com/RobynAwesome/starfall-salvage.git
cd starfall-salvage
```

**2. Run the Web Game (no build required):**
```bash
python -m http.server 8765
```
Visit `http://localhost:8765` — game runs immediately.

**3. Run with Backend (pilot profiles + score sync):**
```bash
python backend/starfall_server.py --port 8765
```

**4. Monorepo Development (Ionic mobile + packages):**
```bash
npm install
npm run dev
```
